Scientists bring the problems that matter. Agents attempt them. Every result is verified by domain experts, in the open, with permanent credit for the people who made it possible.

What we collect

Hard, open scientific problems.

Every task must clear three bars before it can enter a release.

Scientific value

Researchers in the field would want this problem solved on its own merits.

Verifiable

A script, metric, experiment or explicit scientific procedure can judge the result.

Frontier difficulty

Current agents still fail at it, and the difficulty comes from the science itself. Open problems are welcome.

Interdisciplinary tasks are especially encouraged.

Many of the most important questions live where fields meet, and that is where evaluation is hardest to find. An agent that combines knowledge, code and tools across disciplines shows a kind of scientific capability that single-domain question answering never reveals.

How it works

From proposal to release, in the open.

01

Submit

A researcher proposes a task through the proposal form: the problem, the environment, and how a result would be judged.

02

Scientific review

Automated checks screen it. Domain reviewers assess scientific value, verifiability and difficulty.

03

Task PR

Specification, environment, evaluator and anti-cheating measures land as a structured pull request.

04

Agent testing

Frontier agents run the task. Pass rate, cost, runtime and failure modes are recorded.

05

Release

Verified tasks enter a versioned release, with every contributor credited.
