Submit a proposal

Use a proposal to describe a research task before implementing it as a new benchmark. Start at the proposal form.

  1. Sign in with GitHub when the site asks you to.
  2. Describe the scientific area, task objective, available inputs, expected output, and how an answer could be checked. Include data access and reproducibility details where relevant.
  3. Submit the form. The site creates a GitHub Discussion for the proposal and displays it on the task board.
  4. Follow the Discussion for questions and reviews. Use the task page to make edits or provide clarifications requested by reviewers.

The AI review is a recommendation. Wait for an authorized human reviewer to approve the proposal before opening a PR for a new task. Keep the Discussion URL: your task PR must link to it. Read Contribute a new task for the implementation process.
