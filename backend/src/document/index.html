AI4S-Bench contributor guide

AI4S-Bench collects research tasks in AI for Science and packages accepted tasks as reproducible Harbor benchmarks. The public task implementations live in the ai4s-benchmark repository.

Choose a path

  • Submit a proposal to suggest a research task.
  • Apply to review proposals in your field.
  • Review a proposal after your reviewer application is approved.
  • Contribute a new task after its proposal receives human approval.
  • Run the complete example to see a task layout and verifier.

From idea to runnable task

  1. A researcher submits the proposal form. The site creates a GitHub Discussion and lists it on the task board.
  2. AI review may post a recommendation. It is advice for the community, not an approval decision.
  3. An authorized human reviewer publishes a structured review. Reviews remain in the Discussion history; subsequent reviews add new entries.
  4. After human approval, a contributor opens a task PR that links to that Discussion. Maintainers check the decision, task files, and runnable result.

Maintenance of an existing task can go straight to a repair PR. It does not need a new proposal Discussion.
